# 🌡️ India Climate Trends & Temperature Analytics

A **data analytics project** analyzing India's historical temperature data from **1901–2021**, collected from an **official Government of India website**. The project explores long-term, seasonal, and decadal temperature trends through data analysis and visualization.

## 🚀 Features

* Historical temperature analysis (1901–2021)
* Annual temperature trends
* Seasonal temperature analysis
* Decadal trend analysis
* Rolling average analysis
* Temperature anomaly analysis
* Interactive visualizations

## 🛠️ Tech Stack

**Python | SQL | Pandas | NumPy | Matplotlib | Tableau | Streamlit**

## 🔄 Workflow

```text
Government of India Dataset (1901–2021)
              ↓
     Data Cleaning & Preprocessing
              ↓
      Exploratory Data Analysis
              ↓
    Annual & Seasonal Analysis
              ↓
       Decadal Trend Analysis
              ↓
   Rolling Average & Anomalies
              ↓
       Visualization & Insights
```

## 📊 Analysis Performed

* **Annual Trends** – Studied year-wise temperature changes.
* **Seasonal Trends** – Compared temperature variations across seasons.
* **Decadal Analysis** – Identified long-term changes across decades.
* **Rolling Average** – Analyzed smoothed temperature trends.
* **Temperature Anomalies** – Identified deviations from historical averages.

## 🎯 Objective

To analyze over **120 years of Indian temperature data** and identify significant long-term climate patterns and temperature trends.

## 📈 Dashboard

An interactive dashboard was developed using **Tableau and Streamlit** to visualize the analyzed temperature data and insights.

## 📌 Data Source

Historical temperature data for **1901–2021** was collected from an **official Government of India website**.
